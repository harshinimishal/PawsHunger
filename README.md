# PawsHunger

## About  
**PawsHunger** is a responsive website developed for the NGO **Paws Hunger**, which is dedicated to helping and rescuing animals in need. The website provides an interactive platform for volunteers and donors to engage with the NGO's initiatives.

## Features  
- **Fully Responsive**: Optimized for desktops, tablets, and mobile devices.  
- **Volunteer Registration**: Users can sign up for various volunteer programs.  
- **Donation Information**: Displays bank details for direct donations.  
- **Events & Updates**: Showcases upcoming events, rescue stories, and animal welfare campaigns.  
- **Admin Dashboard**: Allows the NGO to manage volunteers and donation records efficiently.  

## Technologies Used  
- **Frontend**: HTML, CSS, JavaScript (Designed in Figma)  
- **Backend**: PHP  
- **Database**: MySQL  

## Installation  
1. Clone the repository:  
   ```
   git clone https://github.com/yourusername/PawsHunger.git
2. Move to the project directory:
    cd PawsHunger

3. Configure the database:

    Import the provided paws_hunger.sql file into MySQL.
    Update database credentials in config.php.

4. Start a local PHP server:
    php -S localhost:8000

5. Open your browser and visit:
    http://localhost:8000
